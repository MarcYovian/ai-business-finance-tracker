# 📜 Changelog: v1.0.0

**Release Date**: October 18, 2025

This is the initial public release of the AI Business Finance Tracker. This version includes the core features necessary for modern, AI-powered financial management.

---

## ✨ New Features

### 1. Dashboard & Financial Overview

-   **Financial Summary**: At-a-glance cards for Total Income, Total Expenses, and Net Profit/Loss.
-   **Income vs. Expenses Chart**: A monthly bar chart visualizing your financial performance.
-   **Expense Breakdown**: A pie chart showing your spending distribution across parent categories.
-   **AI Insights**: An intelligent analysis of your financial data to highlight important trends.
-   **Recent Transactions**: A list of your latest financial activities.

### 2. Comprehensive Transaction Management

-   **CRUD Operations**: Full capabilities to Create, Read, Update, and Delete transactions.
-   **Transaction Dialog**: A unified dialog for adding and editing transactions with robust form validation using Zod and React Hook Form.
-   **Delete Confirmation**: A confirmation dialog to prevent accidental deletions.
-   **Filtering & Sorting**: Tools to easily filter transactions by type and sort them by date or amount.

### 3. AI Assistant

-   **Natural Language Processing**: Log transactions and ask questions about your data using plain English.
-   **Intent Classification**: The AI can understand whether you want to log a transaction, query data, or get help.
-   **Context Awareness**: The assistant remembers the context of the conversation for natural follow-up questions.
-   **Validation & Clarification**: The AI asks for confirmation or clarification if your input is ambiguous or incomplete.

### 4. Settings & Configuration

-   **AI Provider Settings**: Configure the application to use either OpenAI or Google Gemini as the AI provider.
-   **Category Management**: A full interface to manage income and expense categories, including support for nested sub-categories.
-   **Fund Source Management**: Add and manage your financial accounts (e.g., bank accounts, cash wallets).
-   **Fund Transfers**: A dedicated dialog to easily record transfers between your fund sources, with support for optional administrative fees.

## 🔧 Technical Improvements

-   **Architecture**: Built on a modern tech stack including React, Vite, Supabase, and TanStack Query.
-   **State Management**: Efficient server state management with TanStack Query, ensuring a fast and responsive user experience.
-   **Database Integrity**: Use of Supabase RPC functions to ensure atomic operations for complex transactions, preventing data inconsistencies.
